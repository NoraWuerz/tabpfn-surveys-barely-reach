# 14_lsms_pcexp -- LSMS-ISA harmonised dataset v2.0

**Source.** LSMS Team, World Bank (2025). LSMS-ISA Harmonised Dataset on
Agricultural Productivity and Welfare, v2.0. Zenodo.
https://doi.org/10.5281/zenodo.15773365. Described in Bentze T, Wollburg P
(2025). A longitudinal cross-country dataset on agricultural productivity and
welfare in Sub-Saharan Africa. Scientific Data 12.
https://doi.org/10.1038/s41597-025-05639-9

**Access.** Open download, https://zenodo.org/records/15773365

**Terms.** CC0 (Public Domain Dedication), as stated in the Zenodo metadata
of the data set, which the World Bank LSMS team released itself.
Redistribution permitted; citation of the data set as above is requested.
Only this harmonised data set is used (file `Household_dataset.dta`); the
original LSMS-ISA survey files of the World Bank Microdata Library, whose
terms of use do not allow redistribution, are neither used nor deposited.

## Deposit tier: population

`data/` holds the prepared source extract, the fixed population and the 50
stored sample draws; `results/` holds the unit-level predictions of the 11
estimators. The deposited files are a modified extract of the source, not the
provider's original files: extract definition, filters and counts are given in
SI Appendix, Section S3 of the paper.
